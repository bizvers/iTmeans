# iTmeans में शब्द जोड़कर मदद कीजिए

आप अपने AI (Claude, ChatGPT, Gemini…) से शब्द लिखवाकर भेज सकते हैं। हर शब्द छपने से पहले **दो दूसरी कंपनियों के AI** उसे जाँचते हैं।
आपके AI की कंपनी जाँच में शामिल नहीं होती। जो शब्द जाँच में फ़ेल हो, वह नहीं छपता।

## मदद करने वालों के लिए: 3 क़दम
1. `prompt.md` खोलिए। ``` के बीच का संदेश कॉपी कीजिए।
2. ऊपर की चार लाइनें भरिए (क्षेत्र, उप-विषय, शब्द, आपका AI) और अपने AI में चिपकाइए।
3. AI का जवाब **बिना बदले** एक फ़ाइल में सेव कीजिए, जैसे `rahul-frontend-1.json`, और iTmeans वाले व्यक्ति को भेज दीजिए।

एक फ़ाइल में 10–30 शब्द ठीक हैं। पूरी फ़ाइल का नमूना: `example.json`।

**Excel पसंद हो तो:** `excel-prompt.md` वाला prompt ChatGPT/Gemini को दीजिए; वह Excel फ़ाइल बनाता है।
उसे `node scripts/import-sheet.mjs <फ़ाइल.xlsx> --ai=ChatGPT` से draft में बदला जाता है (कौन-सी पंक्ति छूटी और क्यों, यह भी बताता है)।

## क्षेत्र और उप-विषय (फ़ाइल में अंग्रेज़ी वाला नाम लिखें)
| क्षेत्र (DOMAIN) | उप-विषय (SUBTOPIC) |
| --- | --- |
| `web-development` वेब डेवलपमेंट | `frontend` फ़्रंटएंड · `backend` बैकएंड · `database` डेटाबेस |
| `video-editing` वीडियो एडिटिंग | `cutting` कटिंग · `color` रंग · `audio` ऑडियो |
| `photo-editing` फ़ोटो एडिटिंग | `retouching` रीटचिंग · `color` रंग · `layers` लेयर्स |

यह सूची 15 नवंबर 2026 की है। नए क्षेत्र admin page से जुड़ते हैं; पक्की सूची `content/taxonomy/taxonomy.json` में है।
सिर्फ़ **चालू** क्षेत्रों के शब्द साइट पर दिखते हैं।

## iTmeans चलाने वाले के लिए: फ़ाइल कैसे चढ़ाएँ
1. GitHub पर प्रोजेक्ट खोलिए → `content/drafts/` फ़ोल्डर → **Add file → Upload files** → फ़ाइल डालिए → **Commit changes**।
   (फ़ोल्डर न दिखे तो **Add file → Create new file** में नाम `content/drafts/` से शुरू कीजिए।)
2. अगले घंटे का चक्र फ़ाइल पढ़ेगा: हर शब्द की वही जाँच, पास हुए शब्द छपेंगे, फ़ेल हुए रोक-सूची में जाएँगे।
3. नतीजा `content/drafts/done/` में `….result.json` फ़ाइल में दिखेगा (published = छपा, held = रुका, कारण के साथ)।
   ग़लत बनी फ़ाइल `content/drafts/failed/` में जाती है, साथ में कारण।
4. छपे शब्द रोज़ सुबह 4:10 के मिलान के बाद साइट पर दिखते हैं।

ध्यान दें:
- इन फ़ाइलों पर रोज़ की सीमा लागू नहीं होती, पर जाँचने वाले मुफ़्त AI की सीमा लागू है। सीमा खत्म हो तो फ़ाइल वहीं रहती है और अगले घंटे बाक़ी शब्द जँचते हैं।
- एक ही शब्द दोबारा भेजा जाए तो उसे छोड़ दिया जाता है ("not in queue")।
- प्रोजेक्ट public है, इसलिए फ़ाइल सबको दिख सकती है: उसमें ईमेल या फ़ोन नंबर न हों।
- "सब रोको" चालू हो तो फ़ाइलें भी नहीं पढ़ी जातीं।
