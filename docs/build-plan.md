| 5 | **बहुभाषी ढाँचा:** शब्द-पहचान, अनुवाद और UI के शब्द अलग | जब तीसरी भाषा चालू हो |

**क़दम 1 की हालत:** `scripts/validate-content.mjs` बना; `npm run build` से पहले अपने-आप चलता है (`npm run validate` अलग से)। चूक पर build रुकता है; चेतावनी छपती है पर रोकती नहीं। जाँच: taxonomy, शब्द (वही 1-कोड-जाँच के नियम, फ़ोल्डर/slug/फ़ाइल-नाम मेल, `related` दोहराव/ख़ुद की ओर), कतार, रोक-सूची, settings, बही। हाथ से लिखे नमूना शब्द (`_note` वाले) के नियम-उल्लंघन सिर्फ़ चेतावनी हैं। `related` में ऐसा slug जो कहीं नहीं है = चेतावनी (डिज़ाइन में अनुमत); क़दम 3 में चूक बनेगा। टेस्ट: `node --test scripts/validate-content.test.mjs`।

**क़दम 2 की हालत:** `site/src/lib/content.ts` अब `content/words` एक बार पढ़कर याद रखता है (सूची और उप-विषय के हिसाब से अलग-अलग ढूँढ भी तैयार)। लौटी सूचियाँ बदली नहीं जा सकतीं। `astro dev` में हर बार फिर पढ़ता है, ताकि बदलाव दिखें। जाँच: `node --test scripts/content-cache.test.mjs` (सैकड़ों बार बुलाने पर भी फ़ाइल-पढ़ाई नहीं बढ़ती)। build 63 पन्ने वैसे ही, समय लगभग 20 से 9 सेकंड।

**क़दम 3 की हालत:** हर शब्द, कतार-प्रविष्टि और रोका शब्द अब `w-xxxxxxxx` id रखता है; `related` id की सूची है और टूटा संदर्भ build रोकता है। पते (`/hi/<domain>/<subtopic>/<slug>/`) वही रहे (64 पन्ने, पहले जैसे)। एक बार के बदलाव में 21+9+159 id बने, 18 पुरानी कतार-प्रविष्टियाँ हटीं (छपे या रुके थे), `related` के 25 नए शब्द कतार में गए। चक्र अब कतार की id को शब्द की id बनाता है और `related` के नाम id में बदलता है। साइट पर बदलाव: जुड़े शब्द अब slug (`cache`) की जगह नाम (`Cache`) दिखाते हैं। CMS में id का ख़ाना और जुड़े शब्द का चुनाव जोड़ा; **यह CMS बदलाव असली CMS में परखा नहीं गया** (उसके लिए hosted साइट चाहिए)। टेस्ट: `node --test agent/cycle/cycle.test.mjs scripts/validate-content.test.mjs scripts/content-cache.test.mjs`।

**Pagefind की हालत (क़दम 3 के बाद, पहले से तय से जल्दी किया):** `site/` में `pagefind` (मुफ़्त, dev-पैकेज) जुड़ा; `npm run build` अब `astro build` के बाद `pagefind --site dist` चलाता है। सिर्फ़ शब्द-पन्ने इंडेक्स होते हैं (हर भाषा का अलग इंडेक्स, `<html lang>` से चुना जाता है); खोज-बॉक्स का रूप और पते वही हैं, नतीजे नाम/अर्थ/कहाँ दिखाते हैं। पुराना `search.json` हटा दिया। जाँच (`node scripts/check-search.mjs`, पहले build चाहिए): हिंदी (कैश, रंग, कलर, लेयर, ए-पी-आई), English (cache, retouch, caching) और मिली-जुली (cache सर्वर) खोज सही पन्ने देती हैं, ग़लत शब्द पर कुछ नहीं। सीमा: `astro dev` में खोज नहीं चलती (इंडेक्स build पर बनता है), `npm run build` + `npm run preview` से देखें; खोज-बॉक्स का दिखावट-परीक्षण असली browser में नहीं हो पाया।
