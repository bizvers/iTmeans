# डिज़ाइन — C, घना कोश (चुना गया)

Figma: https://www.figma.com/design/WEKZk7vJtR9HhKWNyPNY2b
फ़ाइल में "✅ चुना गया: डिज़ाइन C — घना कोश (मुख्य)" वाला हिस्सा ही आधार है। "C · खुला रूप" = बटन से मिलने वाला दूसरा रूप। "विकल्प (नहीं चुना)" = डिज़ाइन A और B, सिर्फ़ संदर्भ के लिए।

## अक्षर (Google Fonts, दोनों देवनागरी + लैटिन)
- **Baloo 2** — शीर्षक, शब्द, लोगो (SemiBold / Bold / ExtraBold)
- **Hind** — पाठ, अर्थ, बटन (Regular / Medium / SemiBold)

## घटक (Figma components)
- `C/WordCompact` — एक पंक्ति: स्तर-बिंदु (नीला बुनियादी, केसरिया आगे का) · शब्द (Baloo 14, एक पंक्ति) · अर्थ (Hind 12, "…" पर कटे)। चुना होने पर नीली पृष्ठभूमि।
